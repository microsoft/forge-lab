# Contributing

This project welcomes corrections and additions to the CVE list.

Most contributions require you to agree to a Contributor License Agreement
(CLA) declaring that you have the right to, and actually do, grant us the
rights to use your contribution. For details, visit
[Contributor License Agreements](https://cla.opensource.microsoft.com).

When you submit a pull request, a CLA bot will automatically determine whether
you need to provide a CLA and decorate the pull request appropriately. Follow
the instructions provided by the bot. You will only need to do this once
across all repositories using the Microsoft CLA.

Before submitting a change:

- Include only CVE identifiers cleared for public disclosure.
- Keep identifiers unique and sorted numerically.
- Do not include vulnerability details, proof-of-concept code, or sensitive
  information.
- Use the process in [SECURITY.md](./SECURITY.md) for security reports.

This project has adopted the
[Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).

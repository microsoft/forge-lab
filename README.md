# Microsoft Security FORGE Lab

This repository publishes findings from Microsoft Security's Frontier
Offensive Research & Generative Exploitation (FORGE) Lab.

## CVE list

The machine-readable CVE list is available in
[`cve/cve.json`](./cve/cve.json).

Only CVE identifiers cleared for public disclosure should be included.

## Third-party content

This repository does not include third-party source code or software
components. CVE identifiers refer to standardized vulnerability records
published by the CVE Program and CVE Numbering Authorities.
